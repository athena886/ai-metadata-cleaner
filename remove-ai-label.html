What an AI label means

What is an AI label on a photo?

“Remove AI label” can mean two different jobs. One is removing an embedded content credential from the image file. The other is trying to change a label already attached to a post inside a social network. Only the first one can be done by editing the file.

Embedded AI metadata

C2PA content credentials are signed manifests that can record how an image was created or edited. IPTC digital source type can mark an image as trained algorithmic media, composite or synthetic. XMP fields may contain similar AI-source details.

These declarations travel with the file until the metadata container is stripped or the image is re-encoded without it.

Platform-side AI labels

Instagram and other platforms may detect an image, remember an upload and display a label inside their own systems. That label is not stored in the copy on your computer, so removing file metadata cannot edit a label that a platform has already attached.

For that reason, clean the original file before uploading. This removes the embedded information the platform can read during a future upload.

The exact fields depend on the source file. When present, the cleaner targets the following metadata groups.

C2PA content credentials

Signed provenance manifests that may describe generation, editing, tools and review history.

IPTC digital source type

XMP AI-source fields

Adobe-style metadata packets that may carry AI-source labels, editing history and software details.

Camera make, model, lens, exposure, ISO, timestamps, author, GPS coordinates and embedded thumbnails.

Does it keep my photos private?

Yes. All processing happens locally in your browser. Your images are never uploaded, this page makes no network requests, and no third-party scripts or analytics are loaded.

What exactly is removed?

The cleaner removes supported C2PA content credentials, IPTC digital source type fields, XMP AI-source metadata and related EXIF data when present. It can also remove GPS coordinates, camera make and model, exposure settings, author, copyright, software tags and embedded thumbnails.

Does it work on JPEG, PNG and WEBP?

Yes. JPEG/JPG, PNG, WebP and GIF receive direct metadata stripping. AVIF, BMP and TIFF are also accepted when your browser can decode them; those less common formats use a local Canvas fallback. The current batch limit is 5 images.
